
<h1 align="center">Amazon Clone – Frontend Project</h1>

<p align="center">
A simple frontend recreation inspired by the Amazon homepage.
</p>

<hr>

<h2>📖 About</h2>
<p>
This project is a basic Amazon-style homepage design built using HTML and CSS.
It is not an exact clone. The layout was created by observing the original design
and recreating it independently for learning purposes.
</p>

<h2>🛠 Technologies Used</h2>
<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>CSS Grid</li>
  <li>Flexbox</li>
</ul>

<h2>🎯 Purpose</h2>
<ul>
  <li>Practice building real-world webpage layouts</li>
  <li>Improve HTML structure understanding</li>
  <li>Learn layout design using Grid and Flexbox</li>
</ul>

<h2>✨ Features</h2>
<ul>
  <li>Navigation bar layout</li>
  <li>Hero section</li>
  <li>Product grid design</li>
  <li>Footer section</li>
</ul>

<h2>📚 Learning Outcome</h2>
<p>
This project helped me understand how to structure and design a webpage
using only HTML and CSS. It improved my confidence in building frontend layouts.
</p>
